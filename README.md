# 🌍 Chill Bumi API

Chill Bumi adalah layanan Backend REST API untuk mengelola data pariwisata, kategori, ulasan, serta menyediakan informasi cuaca real-time menggunakan OpenWeatherMap.

## 🚀 Fitur Utama
- **Autentikasi JWT**: Register & Login aman.
- **CRUD Wisata**: Kelola data tempat wisata dan kategori.
- **Sistem Ulasan**: Pengunjung dapat memberikan rating dan komentar.
- **Integrasi Cuaca**: Cek cuaca terkini berdasarkan lokasi wisata.
- **Search & Filter**: Pencarian wisata berdasarkan nama atau kategori.

## 🛠️ Teknologi
- Node.js & Express.js
- MySQL (Database)
- Sequelize / MySQL2 (ORM/Driver)
- JSON Web Token (JWT)
- Axios (untuk request ke OpenWeatherMap)
